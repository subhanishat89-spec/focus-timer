# ⏱️ Focus Timer

A minimal Pomodoro timer built with vanilla HTML, CSS, and JavaScript. No frameworks and no dependencies.


## ✨ Features
- 🎯 Focus (25 min), Short break (5 min), and Long break (15 min) modes
- 🔵 Animated SVG progress ring
- ⏯️ Start, pause, and reset, with Space as a keyboard shortcut
- 🔔 Sound alert when time is up
- 🪟 Countdown shown in the browser tab title
- 📅 Daily focus session counter saved in `localStorage`
- 🌙 Dark mode and a responsive layout

## 🛠️ Tech Stack
HTML5 · CSS3 · JavaScript (ES6+) · Web Audio API · SVG

## 🚀 Run Locally
```bash
git clone https://github.com/subhanishat89-spec/focus-timer.git
```
Open `index.html` in your browser.
